Notes:
- LaBlanca through Alo Yoga (Egypt) are the original prototype's confirmed
  stores plus its verified candidates — these predate the Foraj seed list and
  were the first stores this project ever scraped.
- Libra Sportswear's real domain is hyphenated (`libra-sportswear.com`); the
  non-hyphenated form does not resolve.
- Magma (Sportswear) is the same brand as `magmasportswear.com`, already
  registered in `egyscraper/stores/shopify_stores.py` — not repeated here.
- Rows from 8tsh through Yonyo were discovered via the locallyeg.com/brands
  vendor directory (August 2026) — see "How brands were sourced" below. Each
  one's own independent site is used here, not locallyeg.com itself.
- Twenty Seven and Wahm: their custom domains (`twentysevenegy.com`,
  `wahmeg.com`) don't resolve to a working storefront; only the underlying
  `*.myshopify.com` subdomain is live. Scrape that directly.
- XC's storefront brand name is "Xced" (xced-eg.com) — a plausible but not
  fully certain match for locallyeg's "XC" listing; verify before trusting.
- Seemly's operator also runs a second live Shopify store, seemlyessentials.com
  (different product count, so likely not a duplicate catalog) — not added as
  its own row since it wasn't one of locallyeg's listed brand names.
- Two stores (8tsh.com, xced-eg.com) have product descriptions containing
  literal leftover HTML/CSS from an AI chat interface (ChatGPT- and
  Claude.ai-style class names respectively) — the sellers evidently pasted
  rich text from an AI assistant into their Shopify description field instead
  of plain text. Harmless: the existing Shopify mapper strips HTML tags down
  to plain text, so scraped descriptions are unaffected. Noted here only in
  case raw `body_html` is ever inspected directly.
- Decked Out through Ordinary Product were discovered via `brands_new.md` (a
  follow-up research round) — see "How brands were sourced" below.
- Blancka's real domain is `blanckaeg.com` (no dash) — `brands_new.md` and a
  first verification pass both tried `blancka-eg.com` (with a dash), which
  does not resolve.
- Fallen Saints: `fallensaints.com` (no `.co`) is an unrelated parked domain;
  use `fallensaints.co`. OBI: the Instagram handle `@obi.clothing` is a
  different, unrelated account from this brand's actual `@obi.boutique`.

## How brands were sourced

This file has grown from four rounds of research, in order:

1. **Original prototype** (LaBlanca through Alo Yoga in the Shopify table) —
   the first stores this project ever targeted, before the Foraj seed list
   existed.
2. **Foraj seed list** (Amina K through Lovely Land, plus the WooCommerce and
   custom-platform tiers) — a curated list of Egyptian fashion/apparel,
   activewear, and kids-clothing brands. 15 brands from that list were
   dropped: no live storefront could be found, or the storefront was actively
   blocked (Cloudflare, expired domain, suspended hosting).
3. **locallyeg.com/brands** (8tsh through Yonyo, plus Crunk) — the vendor
   directory of a marketplace aggregating ~40 small Egyptian brands.
4. **brands_new.md** (Decked Out through Ordinary Product, plus Jozee
   Boutique and NH Designs) — a follow-up research round that mined two more
   Cairo multi-brand marketplaces, Go Native (gonative.eg) and LOKAL
   (lokaleg.com), plus Egyptian fashion-media roundups.

For rounds 3 and 4, **the marketplace itself is never scraped** — locallyeg,
Go Native, and LOKAL were all confirmed to carry only a partial selection of
each vendor's catalog, so each vendor's own independent storefront is used
instead once found.

Brands researched and excluded, by reason:
- **No independent storefront found** (Instagram/WhatsApp/marketplace-only):
  Clother, Dapperz, Fota, Local Town, Saga, Salty, Studio L (locallyeg);
  UNTY, Marsy, Nob Designs, You Make Me Sick, Slits & Bits, The Denim Effect
  (brands_new.md).
- **Real Shopify store, currently unreachable** (worth a periodic recheck,
  not excluded for lack of a site): Nomina (`nominaeg.com` — store
  deactivated, "Unavailable Shop" / HTTP 402, likely a billing lapse, same
  situation as Be-Indie in the Foraj round); Amgaad (`amgaadeg.com` —
  password-gated); OPIO (`opioshop.com` — Shopify headers present but the
  storefront 404s, likely discontinued after a 2023 acquisition); Marisol
  (`marisolcairo.com` — custom-domain SSL certificate expired, Shopify origin
  no longer reachable through it).
- **Not an independent brand**: Locally Essential and Locally Streets are
  locallyeg's own in-house private-label lines, not outside businesses.
- **Out of category scope**: Hayah (skincare), Leaked (perfume), Locken
  (appears to be a haircare brand, not clothing) — matches this project's
  existing fashion-only scope.
- **Duplicate**: "Denjoe" on locallyeg is the same brand as Denjo Co
  (`denjo.co`), already listed above.
